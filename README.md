# JMDB

**Johnny Media Database**

A from-scratch desktop media database built with:

- Electron
- Python
- FastAPI
- SQLite
- JPNH-inspired embedded browser architecture
- VLC / MPV / HTML5 playback
- TMDB / IMDb / OMDb / EMDB / TV Time integrations
- Telegram / YouTube / Spotify integrations

## Current phase

Foundation 0.1.0.

The current build contains:

- Electron desktop shell
- secure preload
- FastAPI backend
- SQLite database
- schema migrations
- health endpoint
- system status endpoint
- application themes
- initial navigation
- test infrastructure

Browser, library scanner, metadata providers, playback and integrations are implemented in later phases.
